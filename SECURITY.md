# Security Policy

## Supported Versions

Only the latest stable release builds are supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1  | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of `Meetily` seriously. If you identify a security vulnerability (such as a local file exposure, privilege escalation, or private data leak), please do not open a public issue.

Please report the vulnerability privately by emailing **meetily@zackriya.com**.

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or a proof-of-concept (PoC) to reproduce the issue.
- Details about your environment (operating system, application build version).

We will acknowledge your report promptly and coordinate the publication of a fix.
