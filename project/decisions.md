# Decisions

- **Windows dictation first:** Ship system-wide Windows dictation before the meeting/calendar diary.
- **Local processing:** Use PulseTalq's local transcription models and a local cleanup model, with raw transcription as the timeout or failure fallback.
- **Focused insertion:** Insert at the captured caret, replace selected text, preserve clipboard contents, and retain recoverable history.
- **Failure visibility:** Store structured redacted diagnostics locally and show actionable failure reasons in history.
- **Upstream compatibility:** Keep PulseTalq `main` clean. Reconcile upstream Meetily changes in a dedicated `integration/upstream-*` branch, and implement PulseTalq outcomes in isolated task branches and worktrees.
- **Cross-runtime multi-agent development:** Use one stable task ID and one isolated branch/worktree per mutable outcome across Techtraders, SALT, Pulse/ProductOps, Claude Cowork, Claude Code, Codex, T3 Code, humans, and shell automation. Completed task branches merge into a coordinator-owned `integration/*` branch; only a validated integration candidate moves to `main`. The repository and linked Git records, not chat sessions, hold product truth. *(locked 2026-09-02 · last opened 2026-09-02 · last edited 2026-09-02)*
- **Installer look follows Deep Focus:** Installer surfaces (app icons, NSIS header and sidebar, WiX banner and dialog, DMG background, bundle metadata) use the Deep Focus brand from `DESIGN.md`, generated only from `scripts/brand/generate-installer-assets.py`; hand-edited installer art is not accepted. Release gates are `scripts/verify-installer-assets.py` before the build and `scripts/verify-installer-branding.ps1` after the Windows build and after install. Existing Meetily installs are left in place: `com.pulsetalq.app` is a separate product with separate data folders, the installer never detects, uninstalls, or modifies Meetily, and the coexistence is documented in `docs/installer-verification.md` rather than handled silently. Legacy Meetily data (`%APPDATA%\com.meetily.ai`, `meetily-recordings`, registry keys) is cleaned up manually by the owner; no in-app migration is built. Publisher, MSI Manufacturer and copyright holder are PolyphronAI (polyphronai.com); the MIT notice for Zackriya Solutions stays in `LICENSE.md`. From this release on, every PulseTalq installer must either install fresh or upgrade an existing PulseTalq in place: the NSIS bundle removes the previous PulseTalq version before installing, the MSI keeps the identifier-derived UpgradeCode so Windows performs a major upgrade, and the updater endpoint stays on `latest.json`. A release whose installer produces a second PulseTalq entry in Installed apps is a blocking defect. *(locked 2026-09-02 · last opened 2026-09-02 · last edited 2026-09-02)*
