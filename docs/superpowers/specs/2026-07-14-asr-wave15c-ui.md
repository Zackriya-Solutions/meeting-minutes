# PR-45c-ui: Hot-word editor UI (Wave 15 hot-word UX)

## Context

PR-45c (commit `bf93522`) wired `initial_prompt` end-to-end through
`whisper_engine::transcribe_audio_with_confidence` and all four call sites
(`audio/import.rs`, `audio/retranscription.rs`,
`transcription/whisper_provider.rs`, `transcription/worker.rs`). That PR
deliberately passed `None` everywhere so existing users see zero behavior
change. This PR closes the loop: let users configure a hot-word / vocabulary
list from the UI so Whisper can bias its decoder toward company names,
project names, and technical jargon.

Chinese meetings are the primary use case — Whisper common-Chinese recognition
is good but trademark / project names hurt CER noticeably.

## What ships

### Backend (Rust)

1. **Migration**
   - `frontend/src-tauri/migrations/20260714000000_add_transcript_hotwords.sql`
     - `ALTER TABLE transcript_settings ADD COLUMN hotwords TEXT`

2. **Model** — `frontend/src-tauri/src/database/models.rs`
   - `TranscriptSetting` gains `pub hotwords: Option<String>` with
     `#[sqlx(rename = "hotwords")]` + `#[serde(rename = "hotwords")]`. Also
     fixes a pre-existing duplicated `#[sqlx(rename = "whisperApiKey")]`
     annotation on `whisper_api_key`.

3. **Repository** — `frontend/src-tauri/src/database/repositories/setting.rs`
   - `save_transcript_hotwords(pool, hotwords)` upserts with NULL when
     the trimmed input is empty (so the column behaves like an optional
     preference).
   - `get_transcript_hotwords(pool) -> Option<String>` returns `None`
     when no list is set or the stored value is whitespace-only.

4. **Tauri commands** — `frontend/src-tauri/src/api/api.rs` + registered in
   `frontend/src-tauri/src/lib.rs`:
   - `api_get_transcript_hotwords() -> Result<String, String>` (empty
     string when not set; saves the TS side a nullable branch).
   - `api_save_transcript_hotwords(hotwords: String) -> Result<...>`.

5. **Provider trait** — `frontend/src-tauri/src/audio/transcription/provider.rs`
   - `TranscriptionProvider::transcribe` gains `initial_prompt:
     Option<String>`. Doc comment makes the "accept-and-ignore for
     unsupported providers" contract explicit.

6. **Provider implementations**
   - `whisper_provider.rs`: forwards `initial_prompt` to
     `engine.transcribe_audio_with_confidence(audio, language,
     initial_prompt)`.
   - `parakeet_provider.rs`: accepts the new arg and `warn!`s once when
     a non-empty prompt is supplied (Parakeet does not support decoder
     prompts).

7. **Call sites** — load hot-words from settings once per chunk / segment
   and forward to the engine:
   - `audio/transcription/worker.rs` (both `Whisper(...)` and
     `Provider(...)` branches).
   - `audio/import.rs`.
   - `audio/retranscription.rs`.

### Frontend (React + Tauri)

8. **TranscriptSettings.tsx** — when `localWhisper` is the active
   provider, render a hot-words editor below `ModelManager`:
   - `<Textarea>` bound to local state.
   - Loads existing value via `api_get_transcript_hotwords` on mount
     (lazy — only when the editor is visible).
   - Save button calls `api_save_transcript_hotwords` and shows a ✓ / !
     status indicator for 2 s.

9. **i18n** — six locales (en-US, en-GB, zh-CN, zh-TW, ja-JP, ko-KR) gain
   `settings.transcript.{hotwords_label, hotwords_placeholder,
   hotwords_help, hotwords_save}`. Default values lean toward Chinese
   meeting vocabulary (`Meetily, OKR, K8s, project-Phoenix`).

### Docs

10. `docs/asr_benchmark_zh.md` — short follow-up paragraph in the
    hot-word section pointing users to the new UI editor.

## Storage contract

- Column `transcript_settings.hotwords` is `TEXT NULL`.
- Empty / whitespace-only user input is normalized to `NULL` on write so
  the engine can use `Option::None` as a zero-cost short-circuit.
- Length cap: whisper.cpp `set_initial_prompt` truncates at ~224 tokens;
  the help text warns users to keep entries short.

## Behavior contract

- When the user has not set a hot-word list the column is `NULL` and the
  engine receives `None`. `params.set_initial_prompt` is NOT called —
  identical to the pre-PR-45c baseline.
- The default Whisper model default stays `large-v3-turbo` (PR-45a).
- Switching providers does not affect stored hot-words; they apply only
  to engines that support decoder prompts.

## Out of scope (deferred)

- Hot-word list per meeting (currently global only).
- Auto-suggest hot-words from past transcripts.
- LLM-based extraction (covered by Wave 14 PR-44b).
- Parakeet native prompt support.
